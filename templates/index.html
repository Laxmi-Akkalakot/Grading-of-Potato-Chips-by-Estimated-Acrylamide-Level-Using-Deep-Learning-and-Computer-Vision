About This System

This system combines two machine learning approaches: MobileNetV2 deep learning for classifying potato chips into Low, Medium, High and Very High categories, and Random Forest regression using image colour features to estimate a numerical acrylamide value.

Note: The numerical value is an experimental image-based estimate derived from dataset-associated labels. It is not a direct chemical measurement and does not replace laboratory testing. Classification confidence is not the probability that the estimated acrylamide concentration is correct.
